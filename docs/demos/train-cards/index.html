車廂卡改用實車插畫Train cards, re-skinned with the rolling-stock artwork

九種車廂卡（八色 + 彩虹車頭）各自對應一款車輛插畫，取自 鐵島企劃-車廂.svg。 黃色卡改用 610型（610.svg），不使用阿里山號。 卡面框線、色帶、色盲符號與張數標籤沿用 apps/web 現行樣式，只替換車輛圖。

黃色
610型（新北捷運）取代原稿的阿里山號。阿里山號插畫已從這份提案中移除。
裁切
每款插畫都從原稿以實際著色範圍量測裁切，並統一為 176 × 79 的 viewBox，因此九張卡的車輛比例一致。
命名
檔案以引擎的 CardColor 命名（art/RED.svg … art/LOCOMOTIVE.svg），class 與 clipPath id 都已加前綴，可安全地並存於同一份文件。
比例
插畫是側視全車，比原本手繪的車廂寬得多；卡面因此把圖釘在上方、左右滿版，下緣留給符號與張數標籤。
夜間塗裝
原稿畫在近黑底上，車身因此接近純白。整片白直接放到深色卡面上會過亮——對卡面約 12:1， 是深色介面裡最刺眼的東西。深色主題把每一階灰依同一個比例壓向深色底（#1a1d20， 比純黑略冷一點），而不是換成另一組手挑的顏色：原稿的灰本來就是中性的， 這裡多加任何色相都會變成「這台車被重新塗裝過」，而不是「這台車在暗處」。 灰階之間的順序與間距都保留，所以每台車的立體感都在，只是不再刺眼——看起來仍然是同一台車。
不動的部分
塗裝色帶與 R20 的彩虹完全不動——那是卡片的身分，車身不再全白之後反而更跳。 車窗與門框原本就是最深的一階，維持不變即可與壓暗後的車身拉開約 2:1，不需要改成「亮著的車窗」。
唯一例外
30G1000型敞車：整台車就是那組深藍黑，壓在最暗的卡面（約 #24272a）上只會變成一個洞， 所以它反過來提亮成有光的鋼藍。車架留在共用的灰階上，仍高於提亮後的車身——敞車就是靠車架被認出來的。
量測
逐像素比對車輛與該張卡面的對比：九張卡「亮到刺眼（>8:1）」的像素全部歸零， 而決定車輛能不能被看成一個物件的外輪廓，低於 1.6:1 的比例也全部是 0%。
切換方式
夜間塗裝寫在插畫自己的 <style> 裡：以 prefers-color-scheme 為預設， 再由 data-theme 覆寫（兩個方向都蓋得過去）。單獨開啟 SVG 檔時只有前者生效，正是預期的行為。
